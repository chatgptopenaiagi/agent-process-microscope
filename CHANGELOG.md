# Changelog

- Established the existing Windows/Tk observability prototype, scoped adapters,
  canonical events, conservative state engine, local recording and passive replay.

documentation changes do not add runtime capabilities. No GitHub-hosted test run,
standalone signed EXE or production certification is implied.
